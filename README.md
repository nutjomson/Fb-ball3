# Game Launcher

เครื่องมือจัดเก็บและเปิดเกม HTML ส่วนตัวผ่านเว็บเบราว์เซอร์

Game Launcher ช่วยให้คุณนำเข้าไฟล์เกม HTML จากอุปกรณ์ เก็บไว้ในเบราว์เซอร์ และเปิดเล่นได้จากคลังเกมของคุณ โดยไม่ต้องอัปโหลดไฟล์เกมไปยัง GitHub หรือเซิร์ฟเวอร์ภายนอก

## คุณสมบัติ

- นำเข้าไฟล์เกม `.html`, `.htm` และ `.txt` ที่มีโค้ด HTML อยู่ภายใน
- เก็บไฟล์เกมไว้ใน IndexedDB ของเบราว์เซอร์
- แสดงรายการเกมที่นำเข้า พร้อมเปิดเล่นได้จากหน้า Launcher
- เปิดเกมผ่าน Blob URL ภายในเบราว์เซอร์
- ส่งออกไฟล์เกมกลับไปยังอุปกรณ์ได้
- ลบเกมที่นำเข้าออกจากคลังได้
- รองรับการใช้งานบนมือถือและหน้าจอขนาดเล็ก

## วิธีใช้งาน

1. เปิดหน้า Game Launcher ด้วยเว็บเบราว์เซอร์
2. เลือกไฟล์เกมจากแอป Files หรือพื้นที่จัดเก็บของอุปกรณ์
3. เกมที่นำเข้าจะปรากฏในคลังเกม
4. กดเปิดเกมเพื่อเริ่มใช้งาน

## การจัดเก็บข้อมูลและความเป็นส่วนตัว

- ไฟล์เกมที่นำเข้าถูกเก็บไว้ใน IndexedDB ของเบราว์เซอร์บนอุปกรณ์นั้น
- Game Launcher ไม่ได้อัปโหลดไฟล์เกมไปยัง GitHub หรือเซิร์ฟเวอร์ของโปรเจกต์
- ข้อมูลจะไม่ซิงก์ข้ามอุปกรณ์หรือข้ามเบราว์เซอร์โดยอัตโนมัติ
- การล้างข้อมูลเว็บไซต์หรือข้อมูลเบราว์เซอร์อาจทำให้ไฟล์เกมที่เก็บไว้ถูกลบ ควรส่งออกไฟล์สำรองเก็บไว้ในอุปกรณ์
- ข้อมูลที่เกมแต่ละเกมบันทึกเองจะขึ้นอยู่กับระบบจัดเก็บและ Origin ที่เกมนั้นทำงานอยู่

## ข้อจำกัด

- รองรับไฟล์ HTML แบบ standalone เป็นหลัก
- ขนาดไฟล์นำเข้าสูงสุด 20 MB
- ไฟล์เกมที่ต้องโหลดทรัพยากรจากอินเทอร์เน็ตยังคงต้องเชื่อมต่ออินเทอร์เน็ตสำหรับทรัพยากรเหล่านั้น
- ความสามารถในการเปิดหน้าต่างหรือแท็บใหม่อาจขึ้นอยู่กับการตั้งค่าและข้อจำกัดของเบราว์เซอร์

## เทคโนโลยี

โปรเจกต์นี้เป็นเว็บแอปแบบไฟล์เดียว ใช้ HTML, CSS, JavaScript, IndexedDB และ Blob URL โดยไม่ต้องติดตั้งแอปเพิ่มเติม
