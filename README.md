# Five Realms — Football Club Simulator

เกมบริหารสโมสรฟุตบอลแบบเล่นคนเดียวบนเว็บเบราว์เซอร์

## โลกฟุตบอลในเกม

- 5 ลีกสมมติ: Aurelia Premier, Crown Coast League, Valdora League, Northmark Championship และ Solis Elite League
- 96 สโมสรสมมติ
- นักเตะสมมติ 1,824 คน พร้อมตำแหน่งและค่าความสามารถเริ่มต้น
- สโมสรในแต่ละลีกมีระดับความแข็งแกร่งและงบประมาณเริ่มต้นแตกต่างกัน
- รายการฟุตบอลถ้วยสมมติ Five Realms Cup: 40 สโมสรจาก 5 ลีก ลีกละ 8 สโมสร แบ่งเป็น 4 กลุ่ม กลุ่มละ 10 ทีม แข่งขันเหย้า–เยือน 18 นัดต่อทีม
- อันดับ 1–4 ของแต่ละกลุ่มเข้ารอบ 16 ทีม ก่อนแข่งน็อกเอาต์เหย้า–เยือนจนถึงรอบชิงชนะเลิศนัดเดียว รวม 389 นัดต่อฤดูกาล

## ระบบหลัก

- เลือกลีกและสโมสรเพื่อเริ่มอาชีพ
- จัดการทีมและรายชื่อนักเตะ
- ซื้อขายนักเตะและจัดการสัญญา
- บริหารงบประมาณและการเงินสโมสร
- จำลองการแข่งขัน ตารางลีก และหลายฤดูกาล
- บันทึกเกมได้หลายช่องในเบราว์เซอร์

## วิธีเปิดเล่น

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ที่รองรับ JavaScript

ข้อมูลบันทึกเกมอยู่ในเบราว์เซอร์และอุปกรณ์ที่ใช้เล่น จะไม่ซิงก์ข้ามอุปกรณ์โดยอัตโนมัติ

## ข้อมูลและทรัพยากร

ชื่อลีก สโมสร นักเตะ และรายการแข่งขันในชุดข้อมูลเริ่มต้นเป็นข้อมูลสมมติที่สร้างขึ้นสำหรับโปรเจกต์นี้ เกมไม่มีความเกี่ยวข้องหรือการรับรองจากสโมสร ลีก สมาคม หรือผู้จัดการแข่งขันจริง

ไฟล์เกมเป็นแบบ standalone ไม่โหลดไลบรารีหรือทรัพยากรจาก CDN ภายนอก

โปรเจกต์นี้ยังไม่มีการกำหนด open-source license
